# 学习总结
通过本次实践作业我系统学习了 **Git 版本控制** 和 **HuggingFace 预训练模型推理** 的完整流程：
## 一、Git 版本控制学习心得
1. **分支管理**：学会创建、切换、合并分支。新建分支可以独立开发功能，不会污染主线代码，适合并行开发。合并分支时如果同一文件在两个分支被修改，会产生冲突，需要手动解决并保留正确版本。
2. **提交与推送区别**：`add`会将文件添加到缓存区；`commit` 仅在本地保存代码快照；`push` 才会将本地所有提交同步到远程 GitHub 仓库。
3. **版本回溯**：可以通过 commit 哈希值回访历史代码状态，查看项目任意阶段的快照，用于复盘和核对实验步骤，且不会破坏当前代码。

## 二、HuggingFace 环境认知
1. HuggingFace 是一套深度学习 Python 库环境，核心包含 transformers、datasets、torch，用于快速加载预训练模型和公开数据集。
2. 无需手动搭建网络结构，一行代码即可调用官方预训练 ResNet 模型，可以简化模型使用流程。

## 三、模型推理与数据适配
1. **输入尺寸适配**：ResNet-50 预训练于 ImageNet，要求 224×224、3 通道 RGB 图片；而 MNIST 是 28×28 单通道灰度图，必须做通道转换和尺寸缩放。
2. **AutoImageProcessor 作用**：自动完成图片 resize、归一化、通道处理，完美适配模型输入规范。

## 四、零样本推理核心理解
预训练模型在通用数据集训练完成后，**直接在全新数据集推理效果很差**。
本次 ResNet 在 ImageNet 训练，直接测试 MNIST 手写数字，准确率极低，属于正常现象，证明预训练模型需要微调才能适配下游任务。

## 五、图像预处理与模型输入适配
预训练模型对输入图像有严格要求。ResNet‑50需要尺寸224×224的三通道RGB图像。MNIST数据集是28×28单通道灰度图。
因此需要两步关键预处理：
1. 通道转换：将灰度图转为RGB三通道图像，满足模型通道维度要求；
2. 图像缩放resize：将原始28×28图片显式缩放至模型需要的224×224分辨率。
AutoImageProcessor可以自动处理，但为了清晰，代码中可以手动使用Resize完成尺寸变换，之后再做归一化与张量转换。
不同数据集和预训练模型之间必须完成输入适配，否则推理会异常。
